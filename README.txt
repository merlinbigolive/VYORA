VYORA WEBSITE — DESIGN PREVIEW

Files are intentionally placed at the ZIP root.

HOW TO PREVIEW
1. Extract VYORA-Website.zip.
2. Open index.html in a modern browser.
3. Internet access is required for Google Fonts and the remote Unsplash demonstration photos.

WHAT IS INCLUDED
- Responsive luxury black and champagne-gold landing page.
- Customer and employee demo signup/login screens.
- Admin demo dashboard with editable flat commission.
- Customer hotel-only appointment request form.
- Demo booking completion verification in admin view.
- Employee demo profile panel and manual payout request flow.
- Membership pricing display in USD.

IMPORTANT — NOT PRODUCTION READY
This is a front-end prototype. Login, customer records, bookings, employee profiles, identity verification, payments, commission accounting, and payout requests are stored only in the current browser session (or simulated in JavaScript) and are not securely persisted. No real payment is collected and no real payout is sent. The profile cards and prices are illustrative. Before public launch, connect a secure backend/database, compliant government-ID verification provider, marketplace-capable payment processor with supported delayed/manual payouts, secure file storage, email/SMS verification, admin permissions, audit logs, and legally reviewed terms/privacy policies. Do not collect or store government ID images in this static demo.

All website files are at the ZIP root; there is no enclosing project folder.
